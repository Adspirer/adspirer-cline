# Changelog

## 1.1.0

- Added the Cline plugin (`plugins/adspirer`): one install registers the MCP server and bundles
  the 14 skills. Installable from this repository with `cline plugin install`.
- Added a marketplace plugin entry; the server entry id is now `adspirer-mcp` so ids stay unique.

## 1.0.0

- Initial Adspirer package for Cline: connector details, install guide for agents, rules,
  14 skills and Cline Marketplace entries, built from the Cursor plugin v1.0.3.
- Approval rules cover Cline's auto-approve, YOLO mode and headless runs.
